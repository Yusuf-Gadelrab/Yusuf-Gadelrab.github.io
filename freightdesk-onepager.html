FreightDesk AI

An AI back-office clerk for small freight brokerages — reads the billing/AR inbox, classifies every email, and drafts the correct reply on a local model. Zero API fees, data never leaves the building.

Founding-client pilots open · $999 + $249/mo · pre-revenue on the product

The Problem

The AR inbox eats a clerk's week.

A small brokerage's billing/AR inbox is a manual workload — POD requests, invoice disputes, rate reconciliation, advance reconciliation, W9 chasing, 30-day past-due follow-up. It either eats a part-time clerk's week (list cost $1,800–2,200/mo) or gets dropped when nobody has time.

The Product

Reads the inbox, drafts the reply.

FreightDesk classifies every incoming billing/AR email and drafts the correct reply with the right numbers and documents attached — on a local AI model, so rates, margins and customer lists never leave the building and there are no per-message API fees. One-click-approval by default; flip a category to auto-send once trusted.

  • Full automated test suite passing across the shipped modules
  • Built and run against a real brokerage's live AR inbox during development (HwyHaul) before productizing
  • Live landing page + pilot booking flow at /freightdesk.html

Why Now

A local model changes the unit economics.

A part-time AR clerk lists at $1,800–2,200/mo; FreightDesk's $249/mo (~$8/day) is roughly 14% of that, and the install is a 3-day process, not a hire. Running the model locally means no rate, margin or customer data ever touches a third-party API — the exact objection a small brokerage owner raises first.
