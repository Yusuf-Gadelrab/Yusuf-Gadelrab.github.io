Accessibility Statement

Last updated July 29, 2026

This site should be usable by everyone, including people using screen readers, keyboard navigation, magnification, or reduced motion settings. This page describes the current state honestly rather than claiming a certification that has not been earned.

Standard being worked toward

The target is the Web Content Accessibility Guidelines (WCAG) 2.2 at Level AA. This site is partially conformant: most of it meets that bar, and the known gaps are listed below rather than hidden.

What is in place

  • Semantic HTML with landmark elements, so screen readers can navigate by region.
  • Text alternatives on meaningful images; decorative images are marked as decorative.
  • Keyboard operability across navigation, links, and form controls.
  • Contrast reviewed against the 4.5:1 minimum for body text.
  • Responsive layout that reflows without horizontal scrolling down to 320px.
  • No auto-playing audio and no content that flashes more than three times per second.

Known limitations

  • Some data visualisations in the browser tools convey information partly through colour and position; equivalent numeric values are shown as text, but the charts themselves are not fully described.
  • Some downloadable PDFs are not fully tagged for screen readers. If you need an accessible version of any document, ask and one will be provided.
  • Third-party checkout pages are outside this site's control.

Feedback

If you hit a barrier, email yusuf.gadelrab06@gmail.com with the page URL and what went wrong. Accessibility reports are treated as bug reports with priority, not as feature requests. Expect a reply within five business days.

Assessment method

Self-evaluated, using automated checks plus manual keyboard and screen reader testing. No third-party audit has been performed, and this page will say so until one has.
