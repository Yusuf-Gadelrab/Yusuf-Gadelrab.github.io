Before you buy

Who these are not for

The whole design has one trade-off at the centre of it: you get a file you own outright, and in exchange you edit text instead of dragging boxes. That is a genuinely bad deal for some people, and it is cheaper for both of us if you find out here.

You want a visual editor

There is no canvas, no drag handles, no undo history. If Canva or Figma is the workflow you actually want, keep it — this will feel like a downgrade.

You will not open a text file

Editing means opening an .html file in a text editor and typing over the sample content. If that sentence made you wince, believe it now rather than after checkout.

You need live collaboration

No shared cursors, no comments, no version history, no permissions. One file, on your disk, edited by you, backed up by you.

Your team edits in Word

You can print a PDF for anyone. There is no .docx or .pptx in any pack, so there is nothing for a colleague to open and edit in Office.

FAQ

The questions worth answering first

Format, license, iPads, refunds. If something is not answered here, email me before you buy rather than after.

What file format do I get, and what software do I need?

Every template is a self-contained HTML file. You open it in any browser to read it, and you edit it in any plain text editor — TextEdit, Notepad, VS Code, whatever is already on the machine. To make a PDF, use the browser's own print dialog and choose Save as PDF. There is no Adobe, no Figma, no Canva, no font to install and nothing to sign into. Each pack also ships a README that lists every editable field and the exact sample strings to find and replace.

Will these work on an iPad?

For reading and printing, yes. Every file is plain HTML, CSS and system fonts, so it opens in mobile Safari or Chrome and prints to PDF through the share sheet exactly as it does on a desktop.

Editing on an iPad is the awkward part. iPadOS has no built-in plain text editor, so you would need a text editor app from the App Store, or you edit on a computer. The documents are also laid out at US Letter and the slides at 1280×720, so a tablet or phone shows them scaled down rather than at full size.

What is the license? Can I use these for paid client work?

Yes. Templates ship under a single-buyer commercial license: use them on unlimited personal and client projects, change anything you like, and charge whatever you want for the work you produce with them. What you cannot do is resell or redistribute the template files themselves as a competing product. The full wording is in the Terms.

Do I get updates?

Yes, free, for as long as I keep maintaining the pack. Fixes and new documents go to the email address used at checkout. The Complete Vault also includes every future pack added to the suite at no extra cost.

How do refunds work?

Email within 14 days of purchase and you get a full refund. No form, no questions, and you do not have to delete the files first. Refunds go back to the original payment method and usually take 5 to 10 business days to appear on a statement. Full text: the Refund Policy.

Do these need internet, an account, or a subscription?

No to all three. Every file in every pack was checked for external requests and there are none: no web fonts, no CDN scripts, no analytics, no tracking pixels, no images pulled from a server. The only external addresses in the files are ordinary links back to this site, and a link is not a request.

So a template renders identically on a plane, on a locked-down work laptop, or in ten years once whatever service was fashionable this year is gone. There is nothing to log into and nothing that renews.

Do I need to know how to code to edit one?

No. The documents ship pre-filled with realistic sample content rather than empty placeholder tokens, so you find the text you want to change, type over it, and save. Each README lists the exact literal strings to find and replace. Colour is the one place a little CSS helps: each file declares its palette in a handful of variables at the top, so changing one line recolours the whole document.

Who should not buy these?

If you want a drag-and-drop visual editor, this is the wrong product — you edit text in a file, not blocks on a canvas. Same if you will not open a text file at all, or if you need live collaboration, comments and version history the way Google Docs and Figma do it. If your team edits everything in Word and PowerPoint, a browser-printed PDF is a handoff, not a working file.

And if you are waiting for social proof, there is none yet. This is a new store and nothing has sold. That is a legitimate reason to hold off.
