DHAHAB Prompt Vault Privacy Policy

Last updated: July 29, 2026 · Applies to the DHAHAB Prompt Vault Chrome extension

The short version

DHAHAB Prompt Vault ("the extension") is built to collect nothing. This policy is short because there is nothing to disclose beyond what is below.

What data the extension handles

The extension stores the prompts, folders, tags, and usage counts you create, using Chrome's built-in chrome.storage.local API. This data:

  • Stays on your device, inside your Chrome profile.
  • Is never transmitted anywhere. The extension makes zero network requests of any kind: no analytics, no telemetry, no crash reporting, no remote config, no ads.
  • Is never sold, shared, or accessed by the developer. There is no server to send it to, and no account to create.
  • Is only readable by the extension itself and by you (via Chrome's extension storage inspector or the built-in Export feature).

What the extension can see on web pages

The content script that powers the command palette and "save selection" feature runs only on four sites: claude.ai, chatgpt.com, gemini.google.com, and perplexity.ai. On those sites it can read the text you have selected (only when you explicitly right-click and choose "Save to DHAHAB Vault") and can insert text into the page's chat composer (only when you explicitly choose a prompt from the command palette). It does not read, log, or transmit anything else on those pages: not your conversations, not your account info, not other page content.

Permissions and why each is needed

  • storage · Save your prompts and folders locally on your device.
  • contextMenus · Add the right-click "Save to DHAHAB Vault" option.
  • commands · Register the keyboard shortcut that opens the command palette.
  • Host access to claude.ai, chatgpt.com, gemini.google.com, perplexity.ai · Inject the command palette and insert text into those sites' composers. No other sites are accessed.

The extension does not request the tabs, scripting, or <all_urls> permissions, and does not read your browsing history.

Data deletion

Uninstalling the extension deletes all of its stored data automatically (this is standard Chrome behavior for chrome.storage.local). You can also clear it at any time from the manager page, or clear individual prompts.

Children's privacy

The extension is not directed at children and collects no personal information from anyone, of any age.

Changes to this policy

If this extension ever adds optional cloud sync or payments, this policy will be updated before that feature ships, and the update will describe exactly what changes and what stays local.
