EventReels

Drop in raw event footage, get back a finished 9:16 highlight reel. No timeline, no editor, no editing skill — the whole pipeline runs on your own machine, zero API keys.

Working prototype · public repo · pre-revenue

The Problem

Nobody edits the footage.

Every event — a rush week, a game, a formal — generates hours of phone video nobody has the patience or the software skill to cut. Hiring an editor is slow; cloud auto-edit tools cost per render and mean uploading other people's faces to a third-party server.

The Product

An editing brain, and a studio to drive it.

reelsmith — a dependency-free Python CLI wrapping ffmpeg. Scene-change detection + audio-energy scoring (0.7 loudness / 0.3 motion) picks the moments; renders 1080×1920 @30fps with cover-crop, fades and −14 LUFS loudness normalization. Paired with a black-and-gold local web studio (port 8910): drag-drop upload, animated pipeline, phone-frame preview, shareable reel pages.

  • Real-footage validated: 4 min handheld video → clean 30s vertical reel
  • 76 automated tests across 8 suites, CI green on every push
  • Timeout-hardened renders + a server-enforced rights/consent gate before any render runs

Why Now

Local-first on purpose.

Video is the one workload where cloud processing gets expensive immediately, and short-form vertical is the format every event already wants posted. Doing the whole thing on-device makes the cost per reel zero and keeps other people's faces off a server — sidestepping the privacy problem, not just the cost one.
